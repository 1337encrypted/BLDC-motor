Website Upload Commands

Use these curl commands to upload website files to the ESP32 LittleFS filesystem. Run these commands from your project directory when you need to update the web interface.

Upload index.html:
curl -X POST -F "file=@data/index.html" http://ESP32_IP/upload
Upload script.js:
curl -X POST -F "file=@data/script.js" http://ESP32_IP/upload
Upload style.css:
curl -X POST -F "file=@data/style.css" http://ESP32_IP/upload
Upload all files (batch):
curl -X POST -F "file=@data/index.html" http://ESP32_IP/upload && curl -X POST -F "file=@data/script.js" http://ESP32_IP/upload && curl -X POST -F "file=@data/style.css" http://ESP32_IP/upload
Replace ESP32_IP with the actual IP address shown above
Run from your project root directory (where 'data' folder exists)
ESP32 must be running with upload endpoint enabled
